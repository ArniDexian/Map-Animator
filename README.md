# Map Animator

Превращает две картинки карты в видео: по карте «проезжает» синий трек от точки A до последней точки, на остановках появляются кружки с буквами A, B, C…

Вход: **чистая карта** и **та же карта с нарисованным синим треком и круглыми маркерами остановок**.
Выход: **MP4-видео** в формате 16:9 (по умолчанию 4K-совместимое, качество близко к максимуму).

Приложение сделано под **macOS** и состоит из двух частей, которые можно использовать независимо:

| Часть | Что это | Для кого |
|---|---|---|
| **Map Animator.app** | Окно с интерфейсом: перетащили карты, выбрали настройки, нажали «Генерировать» | Обычное использование |
| **`animate_map.py`** | Консольная утилита, которую приложение вызывает «под капотом» | Автоматизация, отладка, скрипты |

---

## 1. Быстрый старт (приложение)

1. Откройте **`Map Animator.app`** двойным кликом (лежит в папке проекта).
2. Перетащите на окно два файла: **чистую карту** и **карту с треком** (можно оба сразу — файл со словом `track` в имени считается картой с треком; можно и по одному, и кликом выбрать файл).
3. Подождите 1–2 секунды: приложение проверит карты и покажет, сколько найдено кружков и какая получится длительность.
4. При желании поменяйте настройки (всё запоминается).
5. Нажмите **«Генерировать»**. Внизу идёт полоса прогресса с оставшимся временем.
6. Готовое видео появляется в списке **«Результаты»** (кнопки «▶ Смотреть» и «Показать в Finder»). Файлы лежат в папке **`output/`** с временной меткой в имени, например `animation_redraw_20261017_143332.mp4` — новые файлы старые не перезаписывают. Finder сам не открывается.

Закрыть приложение — закрыть окно или `⌘Q`. Если в этот момент идёт генерация, окно закроется, а приложение дождётся конца и выйдет само (`⌘Q` спросит подтверждение и прервёт генерацию).

### Если приложение не запускается

* macOS не даёт приложениям читать папку «Загрузки» без разрешения. При первом запуске нажмите **«Разрешить»** в запросе, либо выдайте доступ в *Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску*.
* Диагностика: файл `logs/ui_server.log` (ошибки запуска сервера) и `logs/animate_map_*.log` (каждая генерация).
* Иконка в Finder не обновилась — выполните один раз `killall Dock Finder`.

## 2. Интерфейс приложения

### Карты
* Два поля для перетаскивания. После загрузки обеих карт идёт **автопроверка**:
  * **Перепутаны местами** (трек нарисован на «чистой» карте) — карты **автоматически меняются местами**, об этом пишется сообщение.
  * **Трека нет вообще** (карты одинаковые или трек не синий) — ошибка, кнопка «Генерировать» недоступна.
  * **Карты не совпадают** (разные картинки, или одна сдвинута/масштабирована) — ошибка с процентом различий. Вне трека карты должны быть идентичны.
  * **Разные размеры** — ошибка.

### Основное
| Поле | Что делает |
|---|---|
| Режим | `redraw` (по умолчанию) — линия и кружки рисуются заново на чистой карте; `reveal` — проявляется оригинальная картинка с треком |
| FPS | 24, 25, 30, 48, 50, 60 |
| Разрешение | «Как у карты» (вся карта целиком, без кадрирования), «Исходный масштаб, кадр 16:9», либо 4K / 1440p / 1080p / 720p / 480p (всегда 16:9) |
| Кодек | H.264 (по умолчанию, играет везде), H.265 (компактнее, кодируется дольше), MPEG-4 (старый) |
| Качество | Максимальное (почти без потерь) / Высокое / Сбалансированное |
| Паузы | до первого кружка; перед стартом движения; на промежуточных точках; в конце |
| Длительность движения | время, за которое «точка» проходит весь трек |

Под полями показывается **полная длительность видео** с разбивкой: `1 (до кружка) + 1 (перед стартом) + 4 (движение) + 3 × 1.2 (паузы на точках) + 2 (финал)`.

Числа с дробной частью можно вводить и через точку, и через запятую.

**Кадр 16:9.** Видео всегда 16:9: из карты вырезается самая большая область с таким соотношением, по центру трека. Если трек в неё не помещается, в логе будет предупреждение, а края срежутся. Хотите всю карту — выберите «Как у карты».

### Режим `redraw`: линия и маркеры
* Над настройками — **превью** (линия с кружком и буквой). Если загружена карта, фон — кусочек этой карты в реальном масштабе.
* **Стили**: список готовых наборов настроек. Встроенный **«По умолчанию»** (голубой) нельзя удалить или перезаписать. Свой стиль: настройте → «Сохранить стиль» → имя (предлагается автоматически). Одинаковый стиль второй раз не сохраняется. Выбор стиля из списка применяет все его значения. Кнопка «Удалить стиль» удаляет свои стили.
* Поля: цвет и толщина линии (ползунок + число), цвет и радиус кружка, **обводка кружка** (толщина, 0 = без обводки; цвет), цвет буквы, шрифт (SF Pro — системный Mac — и другие системные шрифты), его начертание и размер, галочка «Подгонять размеры под картинку».

> **Подгонять размеры под картинку.** Значения по умолчанию рассчитаны на картинку, где кружок радиусом ~16 px. Если на вашей карте кружки крупнее, все размеры (толщина линии, радиус, обводка, шрифт) умножаются на отношение «реальный радиус / заданный». Выключите галочку, чтобы использовать числа буквально.

### Режим `reveal`: кисти
Оригинальная картинка проявляется кистью, идущей по пути. Пустые поля — автоматически: кисть линии = её реальная толщина + запас; кружок проявляется целиком, вместе с белой обводкой; линия подходит к кружку вплотную, и кружок появляется ровно в момент касания.

### Дополнительно: поиск трека и маркеров
Диапазон синего цвета (HSV), минимальный радиус кружка, обрезка коротких ответвлений, сглаживание пути, порог разницы карт. Менять нужно редко — только если трек другого цвета.

### Результаты, плеер
* Список готовых видео из `output/`. У каждого: **▶ Смотреть** (встроенный плеер) и **Показать в Finder**.
* **Плеер**: пауза/продолжить (пробел или клик по видео), ползунок перемотки, шаг по одному кадру (`←`/`→`), `Shift+←/→` — на секунду, скорость 0,25×–2×, «Открыть во внешнем плеере». Закрыть — `Esc`.

### Прочее
* **RU/EN** — язык интерфейса (по умолчанию как в системе; выбор запоминается).
* **A− / A+** (или `⌘+`, `⌘−`, `⌘0`) — размер текста интерфейса.
* **Сбросить настройки** — вернуть все значения из `config.json`.
* Все настройки, стили, язык и размер текста хранятся в `ui_settings.json` и возвращаются при следующем запуске.
* Пункт **«Документация»** в меню приложения (Map Animator → Документация, или меню «Справка») открывает это описание в отдельном окне.

## 3. Консольная утилита

```bash
cd ~/Downloads/tz
.venv/bin/python animate_map.py --config config.json            # обычный запуск
.venv/bin/python animate_map.py --config config.json --debug    # + картинки маски и пути в папку debug/
```

* Читает карты из `inputs.clean_map` / `inputs.track_map`, пишет видео в `output.video_path`, лог — в `logging.file`. Относительные пути считаются от папки, где лежит конфиг.
* Показывает прогресс-бар (в терминале) или строки «N%» каждые 5% (если вывод перенаправлен).
* Код возврата: `0` — успех, `1` — ожидаемая ошибка (нет файла, карты не совпадают, нет трека…), `2` — непредвиденная.

# Технические детали

## 5. Архитектура

```
Map Animator.app (SwiftUI)
 ├─ запускает:  .venv/bin/python ui.py --no-window           (сервер 127.0.0.1:8765)
 ├─ окно = WKWebView → http://127.0.0.1:8765/               (ui_static/index.html)
 └─ окно «Документация» → http://127.0.0.1:8765/docs        (этот README)

ui.py
 ├─ пишет config_ui.json и запускает:  animate_map.py --config config_ui.json  (подпроцесс)
 ├─ читает его вывод построчно → прогресс/ETA для страницы
 └─ раздаёт страницу, API, видео (с Range)

animate_map.py  → output/*.mp4
```

Интерфейс **ничего не знает об алгоритме**: он только собирает конфиг и запускает скрипт, как это сделал бы человек в консоли. Поэтому алгоритм можно менять независимо от UI.

## 6. Алгоритм (`animate_map.py`)

Шаги пронумерованы так же, как в логе (`[n/5]`).

0. **Проверка входа** (`check_inputs`): считает пиксели «синее и отличающееся» для обоих порядков файлов — если больше у «чистой», карты меняются местами. Затем различия вне трека (дилатация маски трека на 41 px): если их > `max_mismatch_fraction` — ошибка. Откалибровано на реальных картах: у правильной пары 0 %, сдвиг даже на 2 px даёт ≈ 25 %.
1. **Маска трека** (`extract_track_mask`): `absdiff` двух карт (> порога) AND HSV-маска синего; морфологическое закрытие эллипсом 15×15 заливает буквы внутри кружков; мелкие компоненты (< 20 % от самой большой) отбрасываются.
2. **Одномерный путь** (`extract_path`): скелетизация → 8-связный граф → обрезка коротких ответвлений → наибольшая компонента → два самых удалённых друг от друга узла (двойной обход Дейкстры) → кратчайший путь; начало **A — самая южная** точка. Путь сглаживается гауссом; считается накопленная длина. Концы продлеваются до центров крайних маркеров.
3. **Маркеры** (`detect_markers`): distance transform маски; порог радиуса `max(min_circle_radius_px, 1.7 × медианная полуширина линии)` отличает кружки от изгибов линии независимо от масштаба картинки. Центры проецируются на путь, маркеры сортируются по пройденному расстоянию → A, B, C… Затем `trim_tails` отрезает «хвосты» скелета за крайними кружками и ставит первую и последнюю точки пути ровно в их центры.
4. **Расписание кадров** (`build_schedule`): список `(расстояние_по_пути, число_показанных_маркеров)` на каждый кадр. Кружок появляется, когда линия доходит до его **края** (расстояние минус радиус); остановка — на центре.
5. **Рендер** и кодирование. Кадры с одинаковым состоянием (паузы) не пересчитываются.

### Режимы рендера
* **`redraw`** — на копии чистой карты `polylines` по сглаженному пути (круглые концы) + маркеры: обводка (`marker_outline_px`), диск, буква. Буква рисуется Pillow системным шрифтом (маска по реальным границам глифа → центрируется по «чернилам», а не по метрикам шрифта) либо `cv2.putText`, если `marker_font_path` пуст. Шрифт SF Pro — вариативный файл `SFNS.ttf`, толщина выбирается именованным экземпляром (`set_variation_by_name`).
* **`reveal`** — накапливаемая маска кисти; итог = альфа-смешивание чистой и размеченной карт. Кисть линии = реальная толщина линии + запас. Каждый кружок — диск радиусом «синий диск + белое кольцо», измеренным по разнице картинок. Кружки, до которых линия ещё не дошла, **вырезаются из маски** (линия вплотную подходит к ещё скрытому кружку, затем он появляется целиком).

### Кадрирование и авто-масштаб
* `frame_crop` вырезает самую большую область с `output.aspect`, центрированную на bbox трека; затем `resize` до `output.resolution`.
* `autoscale_drawing`: коэффициент = медианный радиус найденных кружков / `marker_radius`; применяется к толщине линии, радиусу, обводке, шрифту (если отличается от 1 больше чем на 15 %).

### Кодирование
OpenCV-писатель в этой сборке **игнорирует любые настройки качества** (и даёт низкий битрейт), поэтому кадры (BGR, сырые) подаются в **ffmpeg** (`imageio-ffmpeg`, статическая сборка с libx264/libx265) через pipe: `libx264 -crf 8…19 -preset slow`, `libx265 -crf 10…21`, `mpeg4 -q:v 1…5`; цвета маркируются **BT.709**, `yuv420p`, `+faststart`. Измерено: на 4K разница с «потолком» формата (4:2:0) ≈ 0,4 дБ. Если ffmpeg недоступен, используется `cv2.VideoWriter` с предупреждением. Размеры делаются чётными.

## 7. Сервер интерфейса (`ui.py`)

Стандартный `ThreadingHTTPServer` на `127.0.0.1:8765` (`MAP_ANIMATOR_PORT` меняет порт). Токен в HTML защищает API от посторонних страниц (`X-Token` или `?t=`).

| Маршрут | Метод | Назначение |
|---|---|---|
| `/`, `/docs` | GET | страница; документация (README → HTML) |
| `/api/defaults` | GET | значения из `config.json` + `DEFAULT_CONFIG` |
| `/api/settings` | GET/POST | запомненное состояние (`ui_settings.json`) |
| `/api/fonts`, `/api/codecs` | GET | системные шрифты (в т. ч. SF Pro), доступные кодеки |
| `/api/upload?kind=` | POST | загрузка карты (тело — файл, `X-Filename`) |
| `/api/analyze` | POST | предпроверка: перепутаны? совпадают? сколько кружков, радиус маркера |
| `/api/generate`, `/api/cancel` | POST | запуск/остановка подпроцесса |
| `/api/status?since=N` | GET | состояние, этап, %, ETA, новые строки лога |
| `/api/outputs`, `/api/reveal`, `/api/video` | GET/POST | список видео, Finder/открыть, раздача видео с Range |
| `/api/busy` | GET | идёт ли генерация (без токена, для оболочки) |
| `/api/alive` | GET | долгое соединение: закрылось окно → сервер завершается через ~5 с (после окончания генерации) |

Ошибки несут машинный `code` + `args` (`sizes_differ`, `no_track`, `maps_mismatch`…), страница переводит их на RU/EN; английский текст — запасной.

Сервер при `SIGTERM` отменяет текущую генерацию и выходит.

Переменные окружения для тестов: `MAP_ANIMATOR_PORT`, `MAP_ANIMATOR_SETTINGS` (другой файл настроек), чтобы тесты не затрагивали работающее приложение и ваши настройки.

## 8. Страница (`ui_static/index.html`)

Один файл, ванильный JS, без сборки. Состояние: `cfg` (копия `config.json` + служебные ключи `__debug`, `__resPreset`), `styles`, `lang`, `uiScale`, сохраняются в `/api/settings` с задержкой 300 мс. Переводы — словарь `I18N`. Поля формы строятся из таблиц `MAIN`/`REDRAW_*`/`REVEAL`/`DETECT`; добавить параметр = добавить строку в таблицу + ключ в `I18N`. Превью — `<canvas>`; масштаб зависит только от карты (найденный радиус маркера) и сужается, если маркер или линия не помещаются.

## 9. Оболочка macOS

`launcher/MapAnimatorApp.swift` — SwiftUI-приложение: запускает `ui.py`, показывает `WKWebView`, окно документации, меню. **Почему не shell-скрипт в `.app`:** macOS проверяет доступ к «Загрузкам» по исполняемому файлу; у скрипта это `/bin/bash`, и разрешить доступ нельзя. Нативный бинарник имеет собственную идентичность. Сборка: `./build_app.sh` (`swiftc -parse-as-library`, иконка `AppIcon.icns`, подпись ad-hoc). Закрытие окна: если генерация идёт — приложение остаётся и выходит само по её окончании; статус `busy` кэшируется в фоне, чтобы закрытие не зависало.

## 10. Проверка и подводные камни

* Прогон без интерфейса: `MAP_ANIMATOR_PORT=8777 MAP_ANIMATOR_SETTINGS=/tmp/s.json .venv/bin/python ui.py --no-window` и открыть `http://127.0.0.1:8777/` в браузере.
* Быстрая проверка качества: сравнить кадр видео с отрендеренным кадром (PSNR); декодировать нужно с `in_color_matrix=bt709`, иначе OpenCV внесёт собственную ошибку цвета.
* OpenCV `VideoWriter`: параметры качества/битрейта не действуют — не пытайтесь их «подкрутить», используйте ffmpeg-путь.
* Не ломайте контракт «UI → `config_ui.json` → `animate_map.py`»: все новые параметры сначала добавляются в `DEFAULT_CONFIG` и `config.json`.
* Тестовые файлы и лог тестового сервера лежат в `logs/`; `output/`, `debug/`, `logs/`, `config_ui.json`, `ui_settings.json`, `.ui_uploads/` в git не попадают.

# Upload samples

AI-generated PNG assets with transparent backgrounds for testing custom start/finish image uploads:

- `tree.png` — green tree.
- `coffee.png` — takeaway coffee cup.
- `motorcycle.png` — red motorcycle seen from above, pointing up.

Choose **Custom image** for a start or finish icon and select one of these files. All are within the UI upload limits (2 MB, 4096 px); the uploader normalizes them to at most 256 px while retaining alpha and aspect ratio.
